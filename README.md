# OpenQuest

> Open-source quests that lock you out until you touch grass.

OpenQuest is an open-source mobile web app that sends you on location-based
outdoor quests generated by a local LLM. You open the app, accept a quest
("walk to the bakery 1.2 km away and photograph its bread shelf"), and the
app locks your phone's internet for one hour. You can't doomscroll. You can't
check Instagram. The only thing your phone can do is navigate, call emergency
numbers, and verify your quest completion.

Take the photo at the location, the on-device multimodal model judges it, and
if you pass — phone unlocks. If you fail or the hour runs out — phone unlocks
anyway (with a graceful 24h panic PIN escape hatch for safety).

## Why open beats closed

A closed app that locks your phone is a privacy dystopia. Who decides when
you're locked out? Where does your location data go? OpenQuest works because
every piece is auditable:

- The LLM that generates your quests runs **on your device** — Gemma 4 E2B via
  WebGPU, no cloud, no API costs.
- The lockout logic lives in a tiny Android companion app you can read in an
  afternoon (~200 lines of Kotlin).
- The panic PIN is yours, stored in the Android Keystore, encrypted at rest.
- There is no server you don't control.

## Stack

| Layer       | Choice                                              |
|-------------|-----------------------------------------------------|
| Frontend    | React 19 + Vite + TypeScript + Tailwind 4           |
| Local LLM   | Gemma 4 E2B (2-bit QAT) via Transformers.js + WebGPU |
| Quest data  | OpenStreetMap Overpass API + IndexedDB cache        |
| Backend     | Cloudflare Workers + D1 + R2 (optional sync)       |
| Companion   | Kotlin + Jetpack Compose + VpnService               |
| Comms       | Localhost HTTP (PWA <-> companion)                 |
